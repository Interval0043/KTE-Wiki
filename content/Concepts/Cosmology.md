> Dimensions used to have rigid boundaries, but this changed at the end of [[TFCT (Age of Fear)]] upon [[Dire Will]]'s death. Since then, we've used the Region system.

Our roleplays will function on two different systems at once, starting with the simple system.

## Regional System

A Region is an area of arbitrary size, given a number. It can span multiple dimensions, multiple alternate universes, or sitting within a small part of a dimension. The ID of the region is first-come-first-serve, with new regions simply counting up. The ID has no location information, but can point to information about the region.

Present in the Wiki, in Location Pages, will be the Regions. Each *established* Region is *required* to have a Location Page.
